# Mind Play

**Think Curious. Play Smarter.**

## About the Project
Mind Play is an interactive brain-games website designed to provide fun and engaging mental challenges. It includes games that encourage users to practise memory, logic, number patterns, attention, and problem-solving.

## Features
- Multiple brain games
- Three difficulty levels: Easy, Medium, and Hard
- Interactive game controls
- Score tracking
- Progress dashboard
- Recent activity
- Responsive website design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage

## Project Structure
- `index.html` — Main website page
- `css/` — Website and game styling
- `js/app.js` — Main website functionality
- `js/progress.js` — Progress tracking
- `js/games/` — Individual game files
- `assets/` — Logo and website assets

## How to Run
1. Open the Mind Play project folder in Visual Studio Code.
2. Install the Live Server extension.
3. Open `index.html`.
4. Right-click and select **Open with Live Server**.

## Progress Tracking
Mind Play uses browser Local Storage to save game progress on the same device and browser.

## Purpose
The purpose of Mind Play is to make mental practice more engaging through interactive games and challenges.
